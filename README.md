# Java Learning – Beginner Exercises

## Project Overview
This project contains beginner-level Java programs created to learn Java fundamentals and practise basic programming concepts.

## Development Environment
- **Programming Language:** Java
- **JDK Version:** 21
- **IDE:** IntelliJ IDEA Community Edition
- **Version Control:** Git and GitHub
- **Operating System:** macOS

## Topics Covered
- JDK, JRE and JVM
- Java program structure, classes and main method
- Variables and primitive data types
- Type conversion and type casting
- Operators and user input using Scanner
- Conditional statements (if-else)
- Switch statements
- For and while loops
- Methods
- Arrays

## Exercises Completed

| File Name | Description |
|---|---|
| Ex01_HelloVariables.java | Variables and data types |
| Ex02_TypeConversion.java | Type conversion |
| Ex03_Calculator.java | Basic arithmetic operations |
| Ex04_EvenOdd_Grade.java | Conditions and grade calculation |
| Ex05_MultiplicationTable.java | For loop practice |
| Ex06_Methods.java | Creating and calling methods |
| Ex07_ArrayStats.java | Array operations and statistics |
| Ex08_NumberGuessGame.java | While loop and number guessing |
| Ex09_SwitchCalculator.java | Calculator using switch statements |

## How to Run the Programs

1. Install JDK 21.
2. Open the project in IntelliJ IDEA.
3. Open the `src` folder.
4. Select the Java file you want to run.
5. Click the Run button.
6. Enter the required input in the console.

## Learning Outcome

Through these exercises, I practised writing, compiling and running Java programs. I learned how to use variables, operators, conditions, loops, methods, arrays and user input.

I also practised basic Git commands to manage and track my project files.
